# 말로만들DOT 만들기교실

지니와 어스가 함께하는 유아용 만들기 서비스의 첫 화면 프런트엔드 초안입니다.

## 실행하기

Python이 설치되어 있다면 이 폴더에서 아래 명령을 실행한 뒤 브라우저에서 [http://localhost:8000](http://localhost:8000)을 열어주세요.

```bash
python -m http.server 8000
```

별도의 패키지 설치나 빌드 과정은 필요하지 않습니다. 브라우저에서 `index.html`을 직접 열어도 미리 볼 수 있습니다. 말풍선에 사용한 개구체는 Google Fonts에서 불러오기 때문에 해당 글꼴을 보려면 인터넷 연결이 필요합니다. 연결되지 않을 때는 기본 글꼴로 표시됩니다.

## 현재 구현된 화면

- 지니와 어스의 대기 영상이 자동으로 반복 재생됩니다.
- 말풍선의 문장이 한 글자씩 나타납니다.
- **만들기 시작하기**를 누르면 인사 영상이 재생되고 대기 화면으로 돌아갑니다.
- **내 작품**, **도움말**은 말풍선 문구가 바뀌는 시연용 버튼입니다.
- 기기의 동작 줄이기 설정이 켜져 있으면 영상과 글자 애니메이션을 줄입니다.

아직 다른 화면으로의 이동, 작품 저장, 아두이노 기능 또는 백엔드 연결은 구현되어 있지 않습니다.

## 파일 구성

- `index.html`: 화면 구조
- `styles.css`: 디자인 및 반응형 스타일
- `app.js`: 말풍선과 영상 전환 동작
- `assets/`: 사용자 제공 캐릭터 영상, 영상 대기 이미지, 아이콘 라이선스

아이콘은 [Lucide](https://lucide.dev/)를 사용하며 ISC 라이선스입니다. 자세한 내용은 `assets/LUCIDE-LICENSE.txt`를 확인하세요.
